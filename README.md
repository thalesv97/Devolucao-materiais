# Devolução de materiais (spools)

Site do sistema de devolução de spools, publicado pelo GitHub Pages.

Este repositório tem **só o código**. Os dados (NFs, base de spools, histórico de baixas) ficam num repositório
**privado** separado. O site lê e grava esses dados pela API do GitHub, com o token de cada usuário. Sem um token
com acesso ao repositório de dados, o site não mostra nada.

Não envie para cá `dados.js`, `dados.json`, planilhas ou backups.
